# 交付报告模板（执行层）

版本：v1.0  
层级：宪法 `HUMAN_AGENT_PARADIGM.md` v1.0 → 派生规范 `DERIVED_SPECIFICATION.md` v1.0 → 本模板  
状态：执行层模板 · 经所有者授权产出  
适用范围：P7 交付与验收；作为交付单元的一部分，与产品、证据包、可复用资产一并提交

## 使用规则

1. 本报告是证据包的索引与契约对照说明， **不是符合性证明**；符合性以可独立复核证据为准（宪法 9.2）。
2. 任何“已完成/已达成/已通过”字样必须指向证据 ID；没有证据 ID 的结论不得出现。
3. 未完成、失败、未达标必须显式列出；禁止“基本完成”“差不多”“应该可以”等模糊措辞。
4. 验收建议仅为 Agent 自查结论，不构成验收证据；人按契约独立核验后签署。
5. 提交前执行《符合性自检清单》v1.0，并把自检结果附入第 7 节。
