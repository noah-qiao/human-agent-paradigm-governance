# 决策请求与必要信息补全模板（执行层）

版本：v1.0  
层级：宪法 `HUMAN_AGENT_PARADIGM.md` v1.0 → 派生规范 `DERIVED_SPECIFICATION.md` v1.0 → 本模板  
状态：执行层模板 · 经所有者授权产出  
适用范围：P0–P7 中任何需要人回应的交互；Part A 用于必要决策（偏好/价值、授权/责任），Part B 用于 P0/P1 的必要信息补全

## 使用规则

1. 先执行必要性测试：凡 Agent 可自行查明、验证或既有授权覆盖的事项，不得发给人。
2. 禁止提出“怎么做”的能力问题；不得转嫁执行性工作。
3. Part A 决策请求必须六要素齐全（背景摘要、实质选项、推荐、理由、默认选择、决策影响），并写明响应窗口。
4. 偏好/价值类：人逾期未响应可按默认项推进并留痕披露；授权/责任类：不得默认，必须等待明确决定。
5. 每次请求与人的选择均须归档，作为责任归属与追溯凭证。

1. 该事项是否可由 Agent 通过信息获取、推理、验证或既有授权解决？

2. 该事项本质上是人的偏好/价值，还是授权/责任？（只能二选一，并说明依据）
3. 若两可：自决错误代价高且不可逆 → 上报；代价低且可逆 → 自决并事后披露。
