# 契约模板（执行层）

版本：v1.0  
层级：宪法 `HUMAN_AGENT_PARADIGM.md` v1.0 → 派生规范 `DERIVED_SPECIFICATION.md` v1.0 → 本模板  
状态：执行层模板 · 经所有者授权产出  
适用范围：P3 契约确立阶段；一切后续工作的第一判据（在不与宪法及派生规范冲突的前提下）

## 使用规则

1. 本模板由 Agent 在 P3 填写，由人（所有者）确认并签署；契约确立前不得进入设计与实施。
2. C1–C10 一个都不得省略；小任务可以缩短篇幅，但必须逐项回答“是否已定义、判据是什么、证据是什么”。
3. 所有阈值、标准与预算由 Agent 提案，由人确认；Agent 不得单方面放宽，事后修改必须走 C10。
4. 契约 ID 唯一、版本可追溯；每次变更必须记录原因、受影响条款与人的批准。
5. 本契约不得与宪法及派生规范冲突；出现冲突时以上级规范为准，并回到契约流程。

## C4 可靠标准

**完成定义（DoD）：** 只有同时满足以下条件，才允许出现“已完成”声明：

1. 对应 C2 交付项可运行/可使用；
2. 每个完成声明已附真实证据（证据 ID 指向证据包）；
3. 通过 C6 多视角审视，且契约内无未解决缺陷；
4. 失败与未完成项已如实列出。

**声明—证据映射（本项目具体化）：**

| 声明类型        | 必须具备的证据形式                      | 证据去向 |
|:----------------|:----------------------------------------|:---------|
| 功能/交付项完成 | 可运行/可使用产物 + 运行/使用/测试记录  | 证据包   |
| 质量达标        | 评审/测试结果 + 缺陷记录 + 修复复验记录 | 证据包   |
| 状态汇报        | 当前真实状态快照 + 与上一状态差异       | 证据包   |
| 性能达标        | 契约条件测量方案 + 结果 + 环境说明      | 证据包   |
| 复用资产        | 来源 + 验证记录 + 复用结果              | 证据包   |

**状态同步方式：**（何时同步、同步什么、以何种客观指标表示）

**失败报告方式：**（发现失败/未达标后如何报告、内容与时限；禁止模糊措辞）

**禁止行为：** 汇报未发生/未完成事项；以模拟、描述或想象代替真实产出；编造证据或引用不存在之物；以自评替代可复核证据。

## C6 多视角审视要求

| 视角   | 必须寻找的问题                                      | 审视记录要求                       |
|:-------|:----------------------------------------------------|:-----------------------------------|
| 产品   | 意图偏离、范围遗漏、非目标膨胀、价值主张不成立      | 独立立场、缺陷寻找方法、发现、结论 |
| 用户   | 目标用户能否独立完成、路径、反馈、错误恢复、摩擦    | 同上                               |
| 工程   | 设计合理性、实现工艺、可维护性、质量债、边界        | 同上                               |
| 对抗性 | 假定完成声明为假，寻找反例、异常路径、安全/合规漏洞 | 同上                               |

**独立性：** 审视立场、方法与记录独立于被审视内容的生产过程；同一实体执行须显式切换立场并采用独立方法。

**缺陷关闭：** Blocker/Major 必须修复并复验；Minor 应当修复；任何决定不修复的缺陷必须重开契约、经人批准移出范围并显式披露。

**退出标准：** 达到 C5 全部标准，且契约内无已知未解决缺陷。

## C9 验收方式

**唯一验收依据：** 本契约（C2–C5、C6、C8）。

**验收动作：** 人对照契约逐条核验证据，签署验收结论与时间；Agent 不得以自证、自评或“看起来符合”代替契约要求。

**禁止：** 验收时临时增加契约外要求；新增要求须回到 P0/P3 重新对齐并重新定价。

## C10 变更、终止与失败处置

| 触发情形                     | 处置                                                                   |
|:-----------------------------|:-----------------------------------------------------------------------|
| 人改变意图/约束              | 回到 P0/P3；受影响部分重新定价                                         |
| 事实与契约冲突               | 停止推进，如实上报，提交转向/重开提案                                  |
| 契约未覆盖且影响方向         | 回到 P3 补充契约                                                       |
| 偏离已确认方向               | 必须先提案并获批准；禁止先做后说或做了不说                             |
| 约束内无法同时满足可靠与优秀 | 停止推进，上报权衡，请求调整约束；禁止静默取舍                         |
| 人中止项目                   | 交付已真实完成的成果、证据与未完成状态说明；不得声称未完成事项为已完成 |
| 验收未通过                   | 按契约缺陷清单修复，或重开契约调整标准                                 |
